# Пульс клиента — фронтенд MVP

Виджет «Пульс клиента» для карточки клиента в SFA (Альфа-Банк).  
Данные загружаются из mock-файла на основе `Проект «пульс клиента» 1.xlsx`.

## Стек

- React 19 + TypeScript
- Vite 6
- React Router 7
- CSS Modules (дизайн в стиле Альфа-Банка)

## Запуск

```bash
cd pulse-client
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

## Переключение темы

В файле `src/config/theme.ts`:

```ts
export const APP_THEME: AppTheme = 'sfa';     // стиль SFA (как на референсе)
export const APP_THEME: AppTheme = 'default'; // исходный standalone-дизайн
```

Откат — одна строка, перезапуск dev-сервера.

## Функциональность MVP

- Круговой индикатор «светофор» (критик / нейтральный / лояльный / нет данных)
- Интерпретация индекса настроения
- Блок VoC: положительные и негативные стороны
- Блок претензий (ClaimCRM)
- AI-рекомендация для клиентского менеджера
- Рекомендации по повышению лояльности
- Поиск клиентов по PIN, названию, ИНН
- 21 клиент из исходного Excel-файла

## Структура

```
src/
  components/   — UI-компоненты (Layout, PulseIndicator, PulseWidget, ClientSidebar)
  data/         — mock-данные клиентов
  pages/        — страницы списка и карточки клиента
  types/        — TypeScript-типы
```

Бэкенд не реализован — все данные статические.

## Демо для заказчика (без сервера)

```bash
cd pulse-client
npm run build:demo
```

Создаётся один файл **`Пульс клиента — демо.html`** в папке `work_ui`.
Его можно отправить заказчику — открывается двойным кликом в Chrome или Edge, сервер не нужен.

Или дважды кликните **`Собрать демо для заказчика.bat`** в корне `work_ui`.
