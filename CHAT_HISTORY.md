## 1. Старт: мокап по скриншотам

**Запрос:** сверстать HTML-мокап iPad-приложения «Кассы самообслуживания — Альфа-Банк» по 5 экранам (старт, комплектация, параметры, сравнение, контакты). Тёмная тема, красный акcent `#EF3124`.

**Сделано:** файл `kassa-mockup.html` — 5 экранов, калькулятор покупка vs подписка, чекбоксы опций (+110 / +730 / +230 / +490 ₽/мес).

## 2. Отправка расчёта на email

**Запрос:** на последней странице отправлять расчёт на почту пользователя.

**Эволюция:**
1. Node-бэкенд `kassa-email-server/` (SMTP) — пользователь предпочёл без бэкенда.
2. **EmailJS** из браузера + **html2canvas** для PNG + **ImgBB** для хостинга картинки (бесплатный план EmailJS без attachments).
3. Файл `kassa-mockup-emails.html` с настройкой ключей в начале скрипта.
4. Шаблон EmailJS — тип **HTML**, картинка через `{{image_url}}`, не через вложение.

**Проблема:** письмо показывало сырой HTML — исправлено (шаблон EmailJS должен быть HTML, не Plain Text).

## 3. iPhone / iOS 17.6.1 — навигация

**Проблема:** не работает переход между страницами в Safari / «Файлах».

**Решение:** отказ от JS-навигации и `display:none/.active`. Переход через **radio + label**:

```css
#page-N:checked + .screen-N { display: flex; }
```

```html
<label for="page-2" class="btn-primary">Далее →</label>
```

Пользователь подтвердил: «Отлично».

## 4. iPhone — кнопки «Рассчитать» и «Получить расчёт»

**Проблемы:**
- «Рассчитать» не срабатывает / не переходит на экран 4
- «Получить расчёт» перезагружает на 1-ю страницу или не реагирует
- Нет текста ошибки, кнопка не меняет подпись

**Попытки исправления:**
- `bindTap`, скрытые checkbox, `onclick`, перенос логики в `<head>`
- Открытие через `file://` блокирует `fetch` (EmailJS, ImgBB)
- `Запуск для iPhone.bat` — локальный HTTP-сервер, правильный IP Wi‑Fi (`192.168.x.x`, не виртуальный `172.24.x.x`)

**Решение для «Рассчитать»:** `<label for="page-4">` + `runCalculation()` для `calcResult` (email).

**Решение для submit:** `bindTap` / `onclick="submitForm()"`, предупреждение при `file://`.

## 5. iPhone — опции (сканер, весы, тумба, монтаж)

**Проблема:** при выборе опций не меняется «Итого за 1 Кассу» и финальный расчёт.

**Причины:**
- `display: none` на checkbox ломает iOS
- `onclick` на `<div>` не срабатывает из «Файлов»
- JavaScript часто не выполняется в Quick Look

**Итоговое решение — CSS-only demo:**
- 4 скрытых checkbox в корне `.ipad` + `<label for="opt-*-cb">`
- **16 предпросчитанных комбинаций** (все галочки вкл/выкл)
- CSS `:checked` + sibling-селекторы показывают нужные цифры на экранах 2 и 4
- Галочки через `.ipad:has(#opt-*-cb:checked) label[...]`
- Расчёт зафиксирован: **50 касс · 3 года**
- Работает **без JavaScript** — подходит для демо заказчику из HTML-файла

Оба файла обновлены: `kassa-mockup.html` и `kassa-mockup-emails.html`.

## 6. Как открыть на iPhone

**Вопрос:** как открыть именно в Safari?

**Ответ:**
- Из «Файлов» часто нет «Открыть в Safari» — это Quick Look, JS/CSS ограничены
- **Демо заказчику:** достаточно отправить `kassa-mockup.html` (CSS-режим)
- **Email + полный JS:** `Запуск для iPhone.bat` → в Safari вручную ввести `http://192.168.x.x:8765/...`
