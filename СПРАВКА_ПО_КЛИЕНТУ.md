# Справка по клиенту — мокап «Кассы самообслуживания» (Альфа-Банк)

**Дата передачи:** 08.08.2026  
**Заказчик / контекст:** демо-калькулятор экономики касс самообслуживания для презентации и пилотной отправки расчёта на email.

> Все API-ключи в архиве **заменены на плейсхолдеры**. Реальные ключи предыдущего разработчика не передаются — их нужно получить самостоятельно (см. `ИНСТРУКЦИЯ_ПОЛУЧЕНИЕ_КЛЮЧЕЙ.md`).

## 2. Две версии — когда какую использовать

### `kassa-mockup.html` — без email

- 5 экранов: старт → комплектация → параметры → сравнение → финал.
- Навигация и пересчёт опций работают **без JavaScript** (CSS + radio/checkbox) — подходит для iPhone из «Файлов» и для отправки заказчику одним HTML-файлom.
- Зафиксированный сценарий: **50 касс · 3 года**, 16 комбинаций опций предпросчитаны.
- Последний экран — «Расчёт готов», без формы и без отправки на почту.

**Когда:** презентация, демо на планшете, быстрый показ без настройки сервисов.

### `kassa-mockup-emails.html` — с email

- Те же экраны + форма (имя, компания, телефон, email).
- По кнопке «Получить расчёт»:
  1. Рендер PNG-картинки расчёта (`html2canvas`)
  2. Загрузка на ImgBB
  3. Отправка письма через EmailJS с картинкой в теле письма
- Ключи задаются в начале `<script>` в файле (сейчас плейсхолдеры `YOUR_*`).

**Когда:** пилот с реальной отправкой расчёта клиенту на почту.

## 3. Быстрый старт

### Демо на компьютере (Windows)

1. Распакуйте архив.
2. Дважды щёлкните **`Запуск мокапа касс.bat`** — откроется `kassa-mockup.html`.

### Демо на iPhone / iPad

1. Скопируйте **`kassa-mockup.html`** на устройство (AirDrop, почта, облако).
2. Откройте в приложении «Файлы» — навигация и опции работают.
3. Email **не отправляется** в этой версии — это нормально.

### Email-версия на iPhone

1. На **компьютере** запустите **`Запуск для iPhone.bat`** (не закрывайте окно).
2. iPhone и ПК — в **одной Wi‑Fi** (не гостевая сеть).
3. В **Safari** на iPhone введите адрес вида `http://192.168.x.x:8765/kassa-mockup-emails.html` (IP покажет bat-файл).
4. Перед этим заполните ключи в `kassa-mockup-emails.html` (см. инструкцию).

> **Важно:** открытие HTML через `file://` блокирует `fetch` — EmailJS и ImgBB не работают. Для email нужен HTTP-сервер из bat-файла.

## 4. Архитектура email-отправки

```
Браузер (kassa-mockup-emails.html)
    │
    ├─ html2canvas → PNG расчёта
    ├─ ImgBB API   → публичный URL картинки
    └─ EmailJS     → письмо клиенту (HTML-шаблон, {{image_url}})
```

**Почему так:** бесплатный план EmailJS не поддерживает вложения — картинка передаётся ссылкой в HTML-шаблоне.

**Альтернатива:** `kassa-email-server/` — свой SMTP через Node.js (Yandex и др.). В проекте оставлен как запасной вариант, основной путь — EmailJS + ImgBB без бэкенда.

## 6. Известные ограничения

| Ситуация | Поведение |
|----------|-----------|
| iPhone «Файлы» → Quick Look | JS может не выполняться — используйте CSS-демо (`kassa-mockup.html`) |
| `file://` + email | Отправка заблокирована — нужен `Запуск для iPhone.bat` |
| EmailJS Plain Text шаблон | Письмо покажет сырой HTML — шаблон должен быть **HTML** |
| Нет ключей ImgBB/EmailJS | Кнопка «Получить расчёт» покажет понятную ошибку |
| Виртуальный IP (172.x, VPN) | iPhone не достучится — используйте Wi‑Fi IP 192.168.x.x |
