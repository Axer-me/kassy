# Инструкция: как получить ключи для отправки email

В репозитории все секреты заменены на плейсхолдеры. **Создайте свои учётные данные** — не запрашивайте пароли у предыдущего разработчика.

**Текущая версия проекта** (`index.html` + `kassa-email-server`) отправляет письма через **SMTP**. Настройка — в файле `kassa-email-server/.env`.

---

## 1. Подготовка

```bash
cd kassa-email-server
npm install
copy .env.example .env    # Windows
```

Откройте `.env` в текстовом редакторе.

---

## 2. Yandex (основной вариант из `.env.example`)

### 2.1. Что нужно

- Ящик `@yandex.ru` (или домен на Yandex 360)
- **Пароль приложения** для SMTP (не пароль от входа на сайт)

### 2.2. Шаги

1. [mail.yandex.ru](https://mail.yandex.ru) → **Настройки** → **Почтовые программы** → разрешить IMAP/SMTP.
2. [id.yandex.ru/security/app-passwords](https://id.yandex.ru/security/app-passwords) → создать пароль для «Почта».
3. Вставить в `.env`:

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@yandex.ru
SMTP_PASS=сгенерированный_пароль_приложения
SMTP_FROM=Альфа-Банк <your@yandex.ru>
PORT=3456
```

### 2.3. Лимиты

- Около **300 писем в сутки** на бесплатном аккаунте.
- При массовой одинаковой рассылке антиспам может временно блокировать отправку раньше лимита.

---

## 3. Gmail (альтернатива)

1. Включите 2FA в Google-аккаунте.
2. [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → пароль приложения.
3. `.env`:

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@gmail.com
SMTP_PASS=пароль_приложения
SMTP_FROM=Альфа-Банк <your@gmail.com>
PORT=3456
```

Лимит: **~500 писем/день**. Учётные данные Gmail **нельзя** использовать с `smtp.yandex.ru`.

---

## 4. Mail.ru

```env
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@mail.ru
SMTP_PASS=пароль_приложения
SMTP_FROM=Альфа-Банк <your@mail.ru>
```

Пароль приложения: настройки безопасности аккаунта Mail.ru.

---

## 5. Проверка

1. **`Запуск мокапа касс.bat`** или `npm start` в `kassa-email-server/`.
2. http://localhost:3456/ → пройти калькулятор → форма на последнем экране.
3. Указать **свой email** → «Получить расчёт →».
4. Проверить почту и http://localhost:3456/api/submissions

### Типичные ошибки

| Ошибка | Решение |
|--------|---------|
| `Не задана переменная окружения SMTP_USER` | Пустой `.env` |
| `535 Authentication failed` | Пароль приложения вместо обычного пароля |
| Письмо не пришло, в `/api/submissions` запись есть | SMTP принял, но письмо в «Спаме» или заблокировано антиспамом |
| На iPhone не работает | `Запуск для iPhone.bat`, Safari, `http://192.168.x.x:3456/` |

---

## 6. Безопасность

- `.env` и `submissions.db` **не коммитятся** в git.
- Не публикуйте пароли в чатах, скриншотах, issue на GitHub.
- Для продакшена — отдельный служебный ящик или транзакционный сервис (SendPulse, Brevo, SES).

---

## 7. Шпаргалка

| Переменная | Откуда |
|------------|--------|
| `SMTP_HOST` | Таблица провайдера выше |
| `SMTP_USER` | Ваш email |
| `SMTP_PASS` | Пароль приложения (не пароль сайта) |
| `SMTP_FROM` | Имя и адрес отправителя в письме |
| `PORT` | Порт локального сервера (3456) |

После настройки см. **`СПРАВКА_ПО_КЛИЕНТУ.md`** — чек-лист приёмки.
