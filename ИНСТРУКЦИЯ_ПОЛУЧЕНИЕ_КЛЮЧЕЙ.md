# Инструкция: как самостоятельно получить ключи для отправки email

В архиве все секреты заменены на плейсхолдеры. **Не запрашивайте ключи у предыдущего разработчика** — создайте свои аккаунты (бесплатных планов достаточно для демо и пилота).

Нужны **два сервиса**:

1. **EmailJS** — отправка письма из браузера  
2. **ImgBB** — хостинг PNG-картинки расчёта (EmailJS free не поддерживает вложения)

Опционально: **SMTP-сервер** через `kassa-email-server/` (раздел 4).

---

## 1. EmailJS

### 1.1. Регистрация

1. Откройте [https://www.emailjs.com](https://www.emailjs.com)
2. **Sign Up** — можно через Google
3. Подтвердите email

### 1.2. Public Key

1. В кабинете: **Account** → **General**
2. Скопируйте **Public Key** (ранее назывался User ID)

Пример вида: `aBcDeFgHiJkLmNoPq`

### 1.3. Email Service (откуда уходит письмо)

1. **Email Services** → **Add New Service**
2. Выберите провайдер (Gmail, Outlook, Yandex и т.д.)
3. Подключите почту по инструкции EmailJS (OAuth или SMTP-пароль приложения)
4. После создания скопируйте **Service ID** (например `service_abc1234`)

> Для корпоративной почты уточните у IT, можно ли использовать сторонний relay. Для теста подойдёт личный Gmail.

### 1.4. Email Template

1. **Email Templates** → **Create New Template**
2. Настройте поля:

| Поле шаблона | Значение |
|--------------|----------|
| **To Email** | `{{to_email}}` |
| **From Name** | Альфа-Банк (или своё) |
| **Subject** | `Расчёт экономики — кассы самообслуживания` |
| **Content type** | **HTML** ← обязательно, не Plain Text! |

3. **Content** — вставьте HTML:

```html
<p style="font-family:Arial,sans-serif;color:#333;font-size:15px">
  Здравствуйте, <strong>{{user_name}}</strong>! Ниже — ваш расчёт.
</p>
<div style="background:#000;padding:16px;border-radius:16px;text-align:center">
  <img src="{{image_url}}" alt="Расчёт" width="680"
       style="max-width:100%;height:auto;border-radius:12px">
</div>
<p style="font-family:Arial,sans-serif;color:#888;font-size:12px;margin-top:16px">
  Покупка: {{purchase_total}} · Подписка: {{subscription_total}} · Экономия: {{savings}}
</p>
<p style="font-family:Arial,sans-serif;color:#999;font-size:11px">
  {{registers}} касс · {{years_label}} · {{options}}
</p>
```

4. Сохраните шаблон, скопируйте **Template ID** (например `template_xyz5678`)

### 1.5. Лимиты бесплатного плана

- Около **200 писем/месяц** (уточняйте на сайте EmailJS)
- Без вложений — поэтому используется ImgBB

---

## 2. ImgBB

### 2.1. Регистрация и API Key

1. Откройте [https://api.imgbb.com](https://api.imgbb.com)
2. Нажмите **Get API Key** (или зарегистрируйтесь на [imgbb.com](https://imgbb.com) и получите ключ в настройках API)
3. Скопируйте **API Key** (длинная hex-строка)

### 2.2. Зачем нужен

Браузер генерирует PNG расчёта → загружает на ImgBB → получает публичный URL → URL подставляется в письмо EmailJS как `{{image_url}}`.

## 3. Прописать ключи в проект

Откройте **`kassa-mockup-emails.html`** в текстовом редакторе.

Найдите блок (примерно строки 1668–1674):

```javascript
const EMAILJS = {
  publicKey:  'YOUR_PUBLIC_KEY',
  serviceId:  'YOUR_SERVICE_ID',
  templateId: 'YOUR_TEMPLATE_ID',
};

const IMGBB_API_KEY = 'YOUR_IMGBB_API_KEY';
```

Замените плейсхолдеры на свои значения:

```javascript
const EMAILJS = {
  publicKey:  'aBcDeFgHiJkLmNoPq',      // Public Key из EmailJS
  serviceId:  'service_abc1234',         // Service ID
  templateId: 'template_xyz5678',        // Template ID
};

const IMGBB_API_KEY = '0123456789abcdef...';  // API Key ImgBB
```

**Сохраните файл. Не коммитьте ключи в публичный git!**

## 4. Проверка отправки

### На компьютере

1. Запустите **`Запуск для iPhone.bat`** (даже для теста на ПК — он поднимает HTTP на порту 8765)
2. Откройте `http://127.0.0.1:8765/kassa-mockup-emails.html`
3. Пройдите калькулятор до конца
4. Заполните форму **своим email**
5. Нажмите «Получить расчёт →»
6. Проверьте почту (и папку «Спам»)

### Типичные ошибки

| Сообщение / симптом | Решение |
|---------------------|---------|
| «Укажите ключи EmailJS» | Не заменены `YOUR_*` в HTML |
| Письмо с `<p style=...>` текстом | Шаблон EmailJS — Plain Text вместо HTML |
| «Не удалось загрузить картинку» | Неверный ImgBB key или лимит API |
| Ничего не происходит на iPhone из «Файлов» | Нужен HTTP через bat + Safari |
| CORS / fetch blocked | Открыто через `file://` — используйте bat |

## 5. Опционально: SMTP через Node (`kassa-email-server`)

Если EmailJS не подходит (корпоративная политика), можно использовать свой SMTP.

### 5.1. Установка

```bash
cd kassa-email-server
npm install
copy .env.example .env
```

### 5.2. Заполнить `.env`

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@yandex.ru
SMTP_PASS=your_app_password
SMTP_FROM=Альфа-Банк <your@yandex.ru>
PORT=3456
```

**Пароль приложения Yandex:** [https://id.yandex.ru/security/app-passwords](https://id.yandex.ru/security/app-passwords)

### 5.3. Запуск

```bash
npm start
```

Сервер раздаёт статику из родительской папки и принимает POST на `/api/send-calculation`.

> HTML-файлы по умолчанию настроены на EmailJS, не на этот сервер. Переключение на SMTP потребует правки JS в `kassa-mockup-emails.html` — в финальной версии проекта использовался EmailJS.

---

## 6. Безопасность

- **Public Key** EmailJS предназначен для клиентского кода, но привязан к вашему аккаунту — не публикуйте в открытых репозиториях без необходимости.
- В EmailJS включите **Domain restrictions** (Account → Security), если деплоите на постоянный домен.
- ImgBB key — секрет; храните локально или в `.env`, не в git.
- Файл `.env` добавлен в `.gitignore` — не удаляйте это правило.

## 7. Краткая шпаргалка

| Что | Где взять | Куда вставить |
|-----|-----------|---------------|
| Public Key | EmailJS → Account | `EMAILJS.publicKey` |
| Service ID | EmailJS → Email Services | `EMAILJS.serviceId` |
| Template ID | EmailJS → Email Templates | `EMAILJS.templateId` |
| ImgBB API Key | api.imgbb.com | `IMGBB_API_KEY` |

После настройки см. **`СПРАВКА_ПО_КЛИЕНТУ.md`** — раздел «Быстрый старт» и чек-лист приёмки.
